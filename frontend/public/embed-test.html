External Embed Test Page

This simulated external website showcases the embeddable FormBuilder chatbot widget. Notice the floating launcher button in the bottom-right corner!

Clicking the launcher loads the interactive form in an isolated container and records responses into the browser's persistent storage, updating your FormBuilder dashboard statistics in real time.

Embed code in this page:
<script src="/widget.js" data-form-id="feedback-survey" defer></script>
